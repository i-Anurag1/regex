# RegexLab Final Release

This release focuses on product-grade interaction design for a compiler-design portfolio review.

Highlights:
- Automata graph rendering redesigned around formal state-machine notation.
- Self-transitions rendered as explicit loops.
- Multiple symbols on the same transition are consolidated.
- State inspector shows incoming, outgoing, and self-loop counts.
- START and ACCEPT semantics are explicit.
- Removed the optional AI assistant from the primary product flow.
- Added Validation Lab for single and batch evidence.
- Removed graph node CSS transforms that interfered with React Flow positioning.
- Preserved Docker API routing and backend health-check configuration.
